# OBS 미리보기 프로젝터 리사이저

[[사용 OBS 플러그인 템플릿]](https://github.com/obsproject/obs-plugintemplate)

## 개요

OBS의 미리보기 프로젝터 창 크기를 지정한 값으로 변경시켜주는 플러그인입니다.

## 지원 플랫폼
 - Windows
 - MacOS, Ubuntu는 현재 지원하지 않습니다.

## 지원 언어
 ### 직접 지원
  - 한국어
  - 영어

 ### AI 번역
  - 일본어
  - 중국어(간체)
  - 중국어(번체)
  - 독일어
  - 프랑스어
  - 이탈리아어
  - 스페인어(스페인)
  - 포르투갈어(브라질)
  - 러시아어

미지원 언어는 영어로 출력됩니다.

## 설치 방법
 - [[링크]](https://github.com/darkpppet/Projector-Resizer/releases/tag/v0.1.0) 에서 zip파일을 다운받습니다.
 - 압축을 해제한 후, obs가 설치된 폴더에 **`bin`** 폴더와 **`data`** 폴더를 그대로 덮어씌웁니다.
 - obs 설치 위치는 보통 **`Program Files/obs-studio`** 입니다.

## 사용 방법
 - **`제어`** 독에 **`프로젝터 리사이즈`** 버튼이 생깁니다.
 - 이 버튼을 누르면, 미리보기 프로젝터 창의 크기가 미리 지정한 값으로 변경됩니다.
 - 상단 메뉴바에 **`프로젝터 리사이저`** 메뉴 → **`설정...`** 에서 해당 값을 지정할 수 있습니다.
 - 기본 값은 1920*1080 입니다.
